# Custard Knights — twelve-track Suno brief

The soundtrack should sound like a ridiculous medieval tournament that becomes a food fight: memorable melodies, comic confidence, real rhythmic drive, and room for the combat sounds. Avoid solemn fantasy ambience, generic cinematic trailers, or a wall of drums. Use instrumental versions throughout gameplay. These are creative prompts, not generated or licensed recordings.

The current menu theme remains enabled. Joshua confirmed on 8 October 2026 that it came from Suno and has commercial-use rights. Keep the existing theme if it already defines the game; track 1's prompt is an optional new version. The other eleven slots activate only when their files exist.

## Shared direction to append to every prompt

Original instrumental game soundtrack. Playful medieval cartoon world, mischievous and heroic, rounded warm production, crisp rhythmic detail, clear melody. No vocals, spoken words, choir, lyrics, realistic battle noises, or embedded game sound effects. Keep the middle frequencies open for sword hits and UI sounds. Strong identity without imitating a named artist or existing soundtrack. Approximately three minutes, with a repeating musical section suitable for editing into a clean gameplay loop. No long silent introduction or abrupt cinematic ending.

Suno may not produce a seamless loop or exact duration. Audition and trim the exported audio at matching musical boundaries before release. Make two or three versions per prompt and choose by how well the music supports actual play, not how impressive its first ten seconds sound alone.

## 1. Custard Knights

**Use:** main menu / the game's musical identity. **Target:** 116 BPM, 2:45–3:15. **File:** `01-custard-knights.wav`.

> A swaggering, very silly medieval tournament anthem at 116 BPM. Open immediately with a catchy four-note brass motif that sounds proudly heroic, then answer it with a cheeky bassoon phrase. Bouncy tuba bass, plucked lute, pizzicato strings, tambourine and compact snare groove. A bright major-key chorus that makes players want to press Start, followed by a lighter tavern-like middle section and a bigger return. Knights taking themselves much too seriously while custard flies everywhere. Charming, energetic, family-friendly instrumental; no vocals or sound effects. Keep the hook memorable and the arrangement uncluttered. Three-minute song with a loopable central section.

## Export and activate

1. Download the chosen recording as WAV, as Joshua requested. Preserve the original export's sample rate and bit depth; do not upsample or convert an MP3 to claim a lossless master. Retain the Suno track link, creation date and commercial-use evidence with the project records. A duplicate compressed export is not required.
2. Put WAV files in `audio/` using the exact filenames above. Run `python scripts/inspect-soundtrack.py "audio/02-a-very-noble-food-fight.wav"` (multiple paths accepted) for a read-only JSON report of PCM duration, encoding, channels, sample rate, peak, possible clipping, leading/trailing silence at −60 dBFS and SHA-256. The inspector accepts integer PCM RIFF/WAVE, including PCM WAVE_EXTENSIBLE; unsupported formats are reported without conversion. Full-scale samples flag possible clipping, and this report does not verify loudness or musical loops.
3. Run `npm run music`. The generated `audio/soundtrack.js` prefers each exact WAV basename, falls back to an existing same-basename MP3, and preserves `menu-theme.mp3` if no replacement menu recording exists. Missing arena tracks stay silent; the wardrobe uses the existing menu theme until its own track is supplied. Packaging regenerates this catalog and already includes WAV assets.
4. Run `npm run package:win` to include the tracks in the Windows build. Chicken Racing and Hot Pie take precedence over the arena track. Other match modes use their arena. Results use victory/defeat, and returning to menus restores the menu cue.
5. Listen to a full match, pause, mute/unmute, change the Music slider, rematch and return to the menu. Check leading silence, loop clicks, clipping and large volume differences alongside sword hits, parries and timer cues. Do a final loudness/loop check on headphones and speakers before submitting the updated build; file inspection alone does not establish that a loop is seamless.

There are twelve prepared slots. Catalog support and an inspection report do not establish that recordings have been generated, downloaded, auditioned or cleared for release; record those steps separately for each selected track.
